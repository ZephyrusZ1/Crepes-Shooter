A game about dodging mobs while simultaneously having the capability to shoot at them with your gun. You also can collect power up to temporarily upgrade your weapon or refill your bullet. This game is a prototype so please expect that some things might not work, but I believe that most things in this game that supposed to work will work properly. I made this game based on godot documentation about 2d game with some of my own mechanic like shootings and collecting power-up. No generative AI were used
Controls: W and arrow up to go up
          S and arrow down to go down
          A and arrow left to go left
          D and arrow right to go right
          Space to shoot
          Mouse to direct where bullet will go
